## 0.1.0

- First release: Azure Blob Storage, Queue Storage and Table Storage in VS Code. Connect with a connection string, an account key, a SAS URL, Azurite in one click, or Microsoft Entra ID.
- Blob tree with paging, ADLS Gen2 folders, open text in a tab (Save writes back with an ETag check), large text shows the first 1 MB, other files open in the matching viewer.
- Transfer queue: streamed block uploads and downloads with progress, Cancel and Retry; drag and drop from the desktop.
- SAS URLs, Content-Type and Cache-Control, access tiers, rename, soft-delete aware delete, read-only connections.
- Queues: peek 32, send (text or Base64), dequeue, clear. Tables: OData query, grid with inline edit, add and delete.
- Zovo Pro (3 free tries each): folder sync with a dry run, usage and cost report.
